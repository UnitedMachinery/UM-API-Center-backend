## 改动

- 先按路径确认平台接口归属，再解析请求、认证、参数校验和查询。未配置的路径返回 API_NOT_FOUND，不写调用日志、不查询账号。
- 已配置接口包含成功、认证失败、停用、参数错误、JSON 解析失败和查询超时的日志。
- 管理员日志增加处理阶段、认证字段是否提供、未知参数数目、内部失败原因。
- AUTH_FAILED 对调用方保持统一；管理员可区分 auth/用户名/密码缺失、账号不存在/停用、哈希无效及密码不匹配。
- 认证和参数校验之前生成脱敏摘要，仅记录定义字段；密码/secret/token 类字段强制隐藏，未定义字段值和复杂对象内容不记录，长文本最多保留 512 字符。
- 前端参数按钮改为详情，增加失败原因与排查提示。原日志缺少的参数和原因无法补回。
- 旧日志查询按 api_id 或当前定义路径确认归属，列表和分页计数使用同一条件。其他应用旧记录仅隐藏，不删除。

3. 按 docs/OPERATIONS.md 备份、先停后端再替换 JAR、启动验证；无需更改 IIS 或 Nginx 路由。
4. 使用新调用验收：同一查询参数分别带正确/错误密码；已定义字段仍展示脱敏摘要，错误密码仅管理员详情标注密码不匹配。
5. 请求未配置路径，确认不新增日志；检查参数错误、停用及成功查询仍有日志。
